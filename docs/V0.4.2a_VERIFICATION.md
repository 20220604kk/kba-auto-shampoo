## 原始碼還原方法

本機 `linedraw-android-scaffold` 已被後續開發更新為 v0.4.3（23），不能直接當成 v0.4.2a 上傳。

從封存的原開發對話取得 v0.4.2a 發行後的 FileChange，反向套用與本專案有關的 15 筆更新，並移除後續新增的 `AppUpdateManager.java`。還原了版本設定、Manifest、清單狀態與選取流程等；原本公司端資料夾保持不變。後續 v0.4.3 另保存在 `development/v0.4.3`。

原始碼來自原專案及修改歷史，不是直接將 JADX 反編譯內容當作可編譯原始碼。

## APK 內容比對

使用 JDK 17、Gradle 8.13、AGP 8.13.2、SDK 35／Build Tools 35.0.0，執行 `assembleRelease` 產生 unsigned APK，再依 ZIP entry 的未壓縮內容逐檔計算 SHA-256。

- 原始已簽章 APK：475 個檔案。
- 重建 unsigned APK：472 個檔案。
- **471 個檔案的內容雜湊完全一致**，包括所有 `classes*.dex`、AndroidManifest.xml、resources.arsc、圖片、assets、原生程式庫及其他執行內容。
- 原 APK 多出 `META-INF/ANDROIDD.RSA`、`META-INF/ANDROIDD.SF`、`META-INF/MANIFEST.MF` 三個簽章檔；重建版尚未簽章。
- `META-INF/version-control-info.textproto` 不同，因為重建發生在新的 Git checkout，屬於來源版本資訊。

這是 APK 內容對應驗證，不宣稱整份 APK 位元組雜湊一致；Release 提供的仍是原始已簽章檔，沒有以重建包取代。
